# Digital Creative Products Research

Отдельный репозиторий для исследования и подготовки коммерческой линейки цифровых продуктов.

## Цель

Найти цифровой продукт, который:
- можно производить быстро и качественно одному;
- не требует собственного сервера/VPS;
- продаётся разово;
- подходит для faceless-модели;
- можно масштабировать сериями и bundles;
- имеет подтверждённый спрос;
- не требует копирования чужого IP.

## Текущее направление исследования

Themed Creative Resource Packs — тематические коллекции цифровых ресурсов: PNG assets, stickers, patterns, digital paper, wallpapers, printables и связанные design resources.

Важно: это пока зафиксированное направление исследования, а не утверждение, что первый SKU уже окончательно выбран.

## Правила проекта

1. Не создавать fake/demo data.
2. Не копировать персонажей, бренды и защищённый IP конкурентов.
3. Не поднимать собственный backend/VPS без отдельной необходимости.
4. Проверять рынок до производства.
5. Отделять факты рынка от наших гипотез.
6. Проценты прогресса менять только после реально выполненной работы и QA.
7. Все существенные решения сохранять в репозитории.
8. Основной коммерческий язык материалов — английский; рабочие объяснения — русский.
