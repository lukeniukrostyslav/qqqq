# B08 — Visual Direction Reset

Date: 2026-09-27

## Decision

The current first-generation journal-page visual system is technically valid but **not yet commercially competitive in visual richness**.

The comparison against current Etsy dark-academia/junk-journal products shows a substantial gap in:
- illustration quality and specificity;
- layered composition;
- believable antique materials;
- typography hierarchy;
- decorative framing;
- integrated ephemera;
- atmospheric storytelling.

Current market examples checked today include Secret Library, Hidden Library, Between the Lines, Scarlet Library, Library of Curiosities, Cursed Library and The Unfinished Novel. ## Honest assessment

The existing SL_JP pages should **not** be treated as the final visual benchmark for the commercial product.

Their strengths are:
- clean structure;
- readable writing areas;
- correct technical production;
- coherent basic palette.

Their weakness is that the visual language is too close to a simple vector template. It does not yet create the tactile, illustrated, collectible feeling visible in stronger market examples.

## New visual target

The target is not to copy competitors.

The target is a more professional original art direction:

1. **Illustrated atmosphere**
   - believable antique library objects and environments;
   - richer silhouettes and object detail;
   - controlled hand-illustrated / painterly treatment.

2. **Material realism**
   - aged paper;
   - ink variation;
   - subtle stains and wear;
   - paper edges and print imperfections;
   - layered archival surfaces.

3. **Composition**
   - asymmetry;
   - focal object + supporting ephemera;
   - framed writing zones;
   - intentional negative space;
   - visual depth.

4. **Typography**
   - stronger title hierarchy;
   - complementary display + archival text;
   - restrained labels and catalog numbering.

5. **Signature motifs**
   - secret-library architecture;
   - books;
   - keys;
   - ravens;
   - wax seals;
   - botanical specimens;
   - catalog cards;
   - manuscript fragments;
   - archival stamps.

6. **Commercial presentation**
   - every page should look like a finished collectible piece, not a blank template with a border.

## Production rule

Do not mass-revise the existing 85 approved assets yet.

First create a small **3-page visual proof set**:
- one writing page;
- one illustrated library/background page;
- one ephemera/collage page.

Compare those three against current market references.

Only after the proof set passes the visual gate should the production system be revised.
