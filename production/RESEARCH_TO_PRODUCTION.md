# Research → Production Gate

Производство первого коммерческого продукта запрещено до прохождения этих ворот.

## Gate 1 — Market
- [ ] конкретная аудитория выбрана;
- [ ] минимум несколько реальных конкурентов изучены;
- [ ] цены зафиксированы;
- [ ] форматы зафиксированы;
- [ ] demand signals зафиксированы;
- [ ] IP risks проверены.

## Gate 2 — Product
- [ ] состав pack;
- [ ] количество assets;
- [ ] размеры;
- [ ] DPI;
- [ ] форматы;
- [ ] структура ZIP;
- [ ] лицензия;
- [ ] preview;
- [ ] README.

## Gate 3 — Production
- [ ] единый визуальный стиль;
- [ ] naming convention;
- [ ] folder convention;
- [ ] source/master files;
- [ ] export pipeline;
- [ ] duplicate check.

## Gate 4 — QA
- [ ] каждый файл открывается;
- [ ] PNG transparency проверена;
- [ ] размеры проверены;
- [ ] DPI проверен;
- [ ] отсутствуют повреждённые файлы;
- [ ] отсутствуют дубликаты;
- [ ] ZIP распаковывается;
- [ ] README/license присутствуют;
- [ ] preview соответствует содержимому.

## Gate 5 — Marketplace
- [ ] title;
- [ ] description;
- [ ] tags/keywords;
- [ ] preview images;
- [ ] price;
- [ ] license;
- [ ] delivery instructions.

Проценты проекта не повышаются за написание этого документа. Процент повышается только после фактического выполнения соответствующего gate.
