# SKU 001 — Visual Style Guide

Дата: 2026-09-27

## Theme

**SECRET LIBRARY — Dark Academia Journaling Kit**

The visual identity must feel like a coherent fictional archive assembled from an old private library.

## 1. Design language

Primary references:
- antique library catalogues;
- aged paper;
- handwritten scholarly notes;
- bookplates;
- archival labels;
- old keys, locks and instruments;
- botanical specimens;
- ravens and other non-branded scholarly motifs;
- restrained gothic details.

Avoid:
- modern corporate aesthetics;
- glossy 3D stock-render appearance;
- cartoon aesthetics;
- generic Halloween imagery;
- excessive horror/blood/gore;
- recognizable movie/game/book franchise imagery;
- random fantasy objects that do not belong to the library concept.

## 2. Composition

Journal pages:
- preserve a clear writing zone;
- decoration should support, not overwhelm, writing;
- use asymmetry sparingly;
- maintain visual hierarchy between title, metadata and body area.

Ephemera:
- should look usable as physical cut-outs;
- leave safe margins;
- avoid tiny unreadable text;
- repeated motifs may vary in placement, but not in visual identity.

Transparent PNG:
- clean silhouette;
- clean edges;
- no unintended matte/white halo;
- subject centered unless an intentional composition requires otherwise.

## 3. Color system

Use a restrained archival palette:
- parchment / aged paper neutrals;
- charcoal / ink darks;
- muted brown;
- desaturated forest or blue-green accents;
- occasional muted burgundy accent.

Do not introduce bright neon colors or highly saturated modern gradients.

Exact palette values will be frozen before B08 batch creation and recorded in the asset manifest.

## 4. Texture

Texture must be intentional:
- paper fibers;
- subtle grain;
- ink variation;
- controlled stains;
- aged edges.

Avoid texture so strong that:
- text becomes difficult to read;
- pages look artificially noisy;
- transparent PNG edges become dirty;
- printing becomes unnecessarily ink-heavy.

## 5. Typography

Where text is part of an asset:
- use fonts with verified commercial rights;
- avoid embedding unlicensed font files in the delivery package;
- maintain a small typography family;
- use readable hierarchy;
- do not use fake historical claims or invented institutional logos.

If a font is not embedded, the README must not imply that the buyer owns that font.

## 6. Cohesion test

Before an asset batch is accepted, compare at least 6 representative assets together:
- one journal page;
- one paper;
- one ephemera piece;
- one transparent PNG;
- one tag;
- one bookmark.

Reject/revise the batch if they look like products from unrelated shops.

## 7. Originality test

For each motif, ask:
1. Is this a generic public-domain-like concept or an identifiable protected work?
2. Did the asset come from an allowed source?
3. Does the final result reproduce a recognizable competitor asset?
4. Does any logo, trademark or franchise-specific visual appear?

Any uncertainty sends the asset back to review rather than into the commercial ZIP.

## 8. Acceptance standard

The product should look like **one collection**, not 90 unrelated files.

B08 must record the final palette, typography choices, source/creation method and asset manifest before mass production.
